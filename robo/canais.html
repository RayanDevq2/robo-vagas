Canais e nichos

Ache criadores do YouTube que podem contratar um editor, por nicho, país e tamanho. Salve os canais, acompanhe o contato e exporte a lista.

Buscar canais

Chave da API do YouTube (necessária para buscar aqui dentro)

É grátis e fica só no seu navegador. No Google Cloud Console: crie um projeto, ative a “YouTube Data API v3” e crie uma chave em Credenciais. Restrinja a chave ao seu site (referenciador HTTP) para ninguém usar a cota por você. Cada busca por nicho gasta 100 dos 10.000 pontos diários.

O e-mail público do canal não vem pela API. Use o botão “Sobre” de cada canal para ver os contatos que o criador deixou.
